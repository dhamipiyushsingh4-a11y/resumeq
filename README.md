# ResumePro AI — ATS Resume Builder

A responsive, browser-based resume builder with job-description keyword matching and 24 selectable resume designs.

## Run it
1. Download and unzip `ResumePro_AI.zip`.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari.
3. Enter your real profile details and paste a job description.
4. Click **Generate tailored resume** or **Analyze ATS match**.
5. Choose a design, then use **Print / Save PDF** to save a PDF.

No installation, account, API key, or server is required.

## Features
- 24 resume design variations.
- Live resume preview.
- Job-description keyword overlap estimate.
- Highlights matched and missing terms.
- Editable profile, summary, skills, experience, education, projects and certifications.
- Export as standalone HTML or print to PDF.
- Responsive layout for desktop and mobile.

## Important limitations
This is a working starter application that runs locally in your browser. Its ATS score is a transparent keyword-overlap estimate, not a proprietary ATS simulation or a guarantee of selection. The tailoring helper does not call a generative AI model; it uses the information you enter and must not invent qualifications or achievements. For production AI tailoring, secure backend integration with an AI provider, authentication, data privacy controls, document parsing and robust DOCX/PDF generation should be added.

## Privacy
Your data is processed in the browser by this local page. Do not publish a filled-in resume or share it publicly unless you intend to.

## New in this version
- Optional profile photo upload with live preview; photo is embedded in exported resume HTML and print/PDF output.
- 24 more clearly differentiated template styles, including editorial, executive, sidebar, academic, developer, creative and minimalist designs.
- Photo is optional: many ATS application workflows recommend a text-first, no-photo resume unless the employer or local norms request one.
